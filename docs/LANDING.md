## 0. 손대기 전에 반드시

**`index.html` 을 직접 고치지 마라.** 생성물이다.
`scripts/gen_site.py` 가 만들고, launchd(`com.sexyflash.momentus-rebuild`)가 **매일 05:45**
`scripts/rebuild.sh` 로 재생성·커밋·배포한다. 직접 고치면 다음 날 아침 조용히 사라진다.

고칠 곳은 두 군데뿐:

| 무엇 | 어디 |
|---|---|
| 스타일 | `scripts/gen_site.py` 의 `KB_CSS` 블록 (`CSS += KB_CSS`) |
| 구조·내용 | 같은 파일 `# ---------- 랜딩 (KB 구성 클론) ----------` 이하 |

고친 뒤 `python3 scripts/gen_site.py` 로 재생성 → 로컬 확인 → 배포.

## 1. 섹션 구성과 데이터 출처

| # | 섹션 | 클래스 | 데이터 |
|---|---|---|---|
| — | 헤더(알약 GNB·검색·다크모드) | `.kb-gnb` | `KB_HEADER` 리터럴 |
| ① | 히어로 (이미지 좌 + 메타 우, 3장 회전) | `.kb-hero` `.kb-slide` | `products.json` → `bar.hero_shots` |
| ② | 최신 콘텐츠 (가로 레일) | `.kb-rail` | `STREAM`(제품 피드) + `content/stories` 최신 10 |
| ③ | 많이 찾는 것 (3열 그리드) | `.kb-grid` | `products.json` → `order[:6]` |
| ④ | 묶어서 보면 더 좋은 것 (시리즈 레일) | `.kb-srail` | 플래너 / 로고 / 기록 / 무료 도구 4묶음 |
| ⑤ | 무엇을 하려고 오셨나요 (카테고리 스크롤러) | `.kb-cats` | `order` 전체 10종 |
| — | 푸터 | `footer.site` | 기존 공용 푸터 그대로(사업자 정보 법적 필수) |

**새 제품이 생기면** `data/products.json` 에 한 줄 넣는 것으로 ③④⑤ + 검색 인덱스가 전부 따라온다.
랜딩에 하드코딩된 제품 목록은 없다. 단 하나 예외가 `KB_WORD` (슬러그 → 영문 카테고리 단어)
— ⑤의 큰 단어 목록에 쓰이므로 새 제품은 여기 한 줄 추가해야 한다.

## 2. 설계 결정과 이유

- **`body.kbp` 스코프.** 랜딩 층은 전부 이 클래스 안에서만 산다. 그래서 다른 32개 페이지는
  `site.css?v=` 해시 한 줄만 바뀌었다(레이아웃 영향 0). 랜딩만 실험하고 싶을 때 안전판.
- **`page()` 훅 3개 추가** — `header` / `body_class` / `head_extra`.
  기본값이면 기존과 **바이트 단위로 동일한 출력**이라 다른 페이지는 회귀 위험이 없다.
- **다크모드는 `<head>` 에서 선결정.** `head_extra` 의 인라인 스크립트가 그리기 전에
  `documentElement.dataset.theme` 을 정한다. 안 그러면 흰 화면이 번쩍인다(FOUC).
  저장은 `localStorage['mmt-theme']`, 없으면 OS 설정을 따른다.
- **검색은 서버가 없다.** 페이지 안에 인덱스 배열(`KB_INDEX`)을 심어 두고 JS 가 훑는다.
  제품 + 이야기 + 외부 스트림. ⌘K / Ctrl+K 로도 열린다.
- **`subgrid` 안 쓴다.** 처음엔 히어로에 썼는데 구형 사파리에서 2단이 통째로 무너진다.
  슬라이드가 각자 자기 격자를 갖는 방식으로 바꿨다.
- **남의 이미지 핫링크 금지.** 카드 비주얼은 `products.json` 의 `shot`(우리 자산)이거나
  아이콘 타일이다. 2026-07-28 에 랜딩 카드 10장이 타사 이미지를 핫링크하던 사고가 있었다.

## 3. 색 — 어디서 바꾸나 (2026-08-04 적용 완료)

브랜드 색은 **`KB_CSS` 최상단 `.kbp{}` 토큰 5개에만** 산다. 톤을 바꾸려면 거기만 고친다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--brand` | `#3182f6` | 히어로 점, 활성 카테고리 표식, 포커스 링, 맨위로 hover |
| `--brand-cta` | `#1b64da` | 흰 글자를 얹는 채운 면 — CTA·활성 내비·전체보기 |
| `--brand-hover` | `#154fae` | 위 요소들의 hover |
| `--brand-tint` | `#eef4ff` | Series 배지 배경, 텍스트 선택 |
| `--on-brand` | `#fff` | 채운 면 위 글자 |

**원칙: 파랑은 장식이 아니라 "행동과 현재 위치"에만.** 제목·본문은 잉크, 배경은 흰색/soft.
큰 카테고리 단어를 통째로 파랗게 칠하지 않고 앞에 18×3px 파란 바만 붙인 것도 같은 이유다.

**왜 파랑이 두 개인가.** `#3182f6` 위에 흰 글자는 대비 3.71:1 로 WCAG AA(4.5:1)에 못 미친다
(15px 굵은 글씨는 '큰 텍스트' 예외에도 안 걸린다). 한 단계 내린 `#1b64da` 는 5.41:1 로 통과하고
눈으로는 같은 파랑으로 읽힌다. 순정 `#3182f6` 하나로 통일하고 싶으면 `--brand-cta` 를
`--brand` 와 같게 두면 된다 — 접근성만 포기하면 되는, 한 줄짜리 선택이다.

다크 모드는 `html[data-theme="dark"] .kbp` 에서 `--brand` 를 `#6aa5ff` 로 올린다(채운 면은 그대로).

## 4. 타이포 — 한글 기준 척도 (2026-08-05 적용 완료)

전엔 12·13·14·15·16·17·19·20·22·26·30·40·42px 가 규칙 없이 섞여 있었다.
"글자가 크다"는 **증상**이었고 원인은 **척도가 없던 것**. 역할 이름으로 10단계만 둔다.
색과 마찬가지로 **개별 규칙에 px 를 박지 마라** — `.kbp{}` 토큰만 쓴다.

| 토큰 | 값(1358px 기준 실측) | 쓰는 곳 |
|---|---|---|
| `--f-micro` | 12px | 배지, 카드 칩 |
| `--f-cap` | 13px | 날짜, 카테고리 카드 설명, 시리즈 번호 |
| `--f-ui` | 14px | 내비, 키커, 시리즈 목록, 전체보기 |
| `--f-ui-lg` | 15px | CTA, 레일 카드 제목, 검색 결과 |
| `--f-body` | 17px | 히어로 설명, 모바일 시트 |
| `--f-title-s` | 16→**18**px | 카드 제목, 카테고리 카드 제목 |
| `--f-title` | 19→**23**px | 섹션 제목 h2 |
| `--f-title-l` | 22→**27**px | 시리즈 패널 제목 |
| `--f-display` | 25→**34**px | 히어로 h1, 검색 입력 |
| `--f-mega` | 27→**38**px | 카테고리 큰 단어 |

자간 `--ls-display -.04em` / `--ls-title -.028em` / `--ls-body -.008em`,
행간 `--lh-tight 1.32` / `--lh-title 1.42` / `--lh-body 1.7`.

**한글에 맞춘 세 가지.** 라틴 기준으로 짜면 한글이 답답해진다.

1. **자간은 크기에 따라.** 클수록 좁히고 작을수록 0 에 가깝게. 본문 크기에 `-.04em` 을 주면
   한글은 획이 뭉쳐 읽기 어려워진다. (전엔 18px 카드 제목에 `-.035em` 이 박혀 있었다)
2. **행간은 라틴보다 넉넉히.** 본문 1.7, 두 줄짜리 제목 1.42.
3. **`text-wrap:balance`** 를 모든 제목에 건다. 제목 마지막 줄에 한 어절만 남는 걸 막는다.
   body 의 `word-break:keep-all`(어절 단위 줄바꿈)과 짝으로 동작한다. 본문은 `pretty`.

날짜에는 `font-variant-numeric:tabular-nums` — 숫자 폭이 흔들리지 않는다.

**척도 밖에 두는 것**(토큰으로 바꾸지 마라): 워드마크 19px(로고에 가깝다),
아이콘 타일·카테고리 이모지 글리프(텍스트가 아니다).

## 5. 남은 숙제 — 우선순위

1. **모바일 실측** — 미디어쿼리(860 / 1000 / 620px)는 넣었지만 **실기기로 못 봤다.** 미검증 상태.
2. **이미지 무게** — `mark.the-moment.us/og-default.png` 가 **2.86MB**이고 화면에선 거의 검게
   보인다. 랜딩 카드·카테고리 카드에 그대로 물려 있어 첫 로딩을 잡아먹는다. 리사이즈하거나
   카드 전용 컷을 따로 만들어야 한다. (히어로의 `draft_user_cover.png` 도 878KB)
3. **한글 서체** — 지금은 시스템 서체(`--sans`)다. macOS 는 Apple SD Gothic Neo 로 괜찮지만
   **Windows 는 맑은 고딕으로 떨어져 인상이 크게 달라진다.** Pretendard(OFL) 자체 호스팅이
   정석이지만 폰트 파일 무게·의존성이 생기므로 대표님 결정 사항으로 남긴다.
4. **섹션 카피** — "많이 찾는 것", "묶어서 보면 더 좋은 것" 은 임시로 붙인 제목이다.
5. **시리즈의 빈 썸네일** — 로고 피드 항목엔 이미지가 없어 그라데이션 타일로 때웠다.

## 6. 배포

```bash
python3 scripts/gen_site.py          # 재생성
npx wrangler deploy                  # 배포 (routes: the-moment.us/*)
git push origin main                 # ⚠️ 반드시 — 안 올리면 다른 기기가 옛 상태로 배포한다
```

`scripts/rebuild.sh` 가 이걸 전부 하되 안전장치가 붙어 있다(생성 실패 시 배포 안 함,
변경 없으면 건너뜀, `origin/main` 이 HEAD 조상이 아니면 중단). 손으로 할 때도 같은 순서를 지켜라.

**배포 직후 루트가 옛 HTML로 보일 수 있다.** 엣지 캐시다(`cf-cache-status: HIT`).
하위 페이지가 새 `site.css?v=` 해시를 주는데 `/` 만 옛것이면 캐시가 맞다 — 몇십 초 뒤 갱신된다.
배포 자체가 실패한 것과 헷갈리지 마라. 판별법:

```bash
curl -s https://the-moment.us/ | grep -c 'class="kbp"'    # 1 이면 새 랜딩
```

## 7. 로컬 미리보기 — 이 맥에서의 함정

이 맥은 포트가 **IPv4/IPv6 이중으로 물려** 있어 충돌이 조용히 난다. 이미 쓰이는 포트에
`http.server` 를 띄우면 바인딩은 되는데 요청은 **남의 서버로** 간다(404·403 이 뜬다).
반드시 `lsof -nP -iTCP:<포트> -sTCP:LISTEN` 으로 비었는지 확인하고 골라라.
알려진 점유: `8765`(FastAPI 리다이렉터) · `8791`(dev.heyreci.com/toon) · `8899`.

외부 공유가 필요하면 cloudflared quick 터널을 쓰되 **두 가지를 지켜라**:

- **`pkill -f "cloudflared tunnel"` 절대 금지.** 이 맥엔 대표님 프로덕션 터널이
  여러 개 떠 있다(reci-dev 네임드, llm 게이트웨이, creagen-apps). 2026-08-04 에
  이걸로 전부 죽였다. launchd `KeepAlive` 가 살려내고 `claude_tunnel.sh` 가 KV 를
  자동 갱신해서 15초 만에 복구됐지만, 운이 좋았던 것이다. **내가 띄운 PID 만 kill 해라.**
- **전용 config 를 물려라.** 그냥 띄우면 `~/.cloudflared/config.yml` 의 ingress 를 주워
  catch-all `http_status:404` 로 떨어진다. `--config <내-config>` 로 격리할 것.
