# SEO/GEO 실험 원장 — 모멘터스 전 사이트

> **왜 이 파일이 있나.** 고치고 → 결과 보고 → 버리면 **남는 게 하나도 없다.**
> 다음에 다른 사이트에서 같은 상황을 만나도 처음부터 다시 추측하게 된다.
>
> 그래서 **한 것 / 왜 될 거라 봤나 / 실제로 어떻게 됐나 / 그래서 일반화되나**를 여기 쌓는다.
> 이게 쌓여야 "우리는 SEO·GEO 를 안다"고 말할 수 있다. 안 쌓이면 매번 초보다.
>
> - **사이트별 진행 중인 가설** = 각 저장소의 `SEO_HYPOTHESES.md` (예: `cue/SEO_HYPOTHESES.md`)
> - **규칙** = `docs/SEO_GEO.md` — 🔴 **규칙은 여기 증거에서만 나온다.** 추측으로 규칙을 쓰지 마라
> - **이 파일** = 그 사이를 잇는 증거 원장

## 판정 기호 — 셋 다 값이 있다

| | 뜻 |
|---|---|
| ✅ **효과 확인** | 재보니 지표가 움직였다. 근거 숫자를 같이 적는다 |
| ❌ **효과 없음** | 재봤는데 안 움직였다. **이게 제일 값나가는 기록이다** — 다음에 같은 걸 또 안 한다 |
| 🌫 **모름** | 다른 변수와 섞여서 못 가린다 / 표본이 부족하다 / 아직 이르다. **모른다고 적는 게 맞다.** 🚫 추측으로 ✅ 를 주지 마라 |
| ⏳ **관찰 중** | 조치는 끝났고 확인일이 아직 안 됐다 |

🚫 **여러 조치를 한 배포에 몰아넣고 ✅ 를 주지 마라.** 그러면 전부 🌫 가 된다.
어쩔 수 없이 몰아넣었으면 **몰아넣었다고 적어라** — 그게 정직한 기록이다.

## 2026-08-28 · cue — 검색엔진별 색인 실측 (구글만 보고 있었다)

**계기:** 구글 색인 0개로 40일째 막혀 있는데, **한국 서비스가 네이버를 한 번도 안 봤다.**

| 엔진 | 색인 | 확인 방법 | 판정 |
|---|---|---|---|
| **구글** | **0개** | GSC | ❌ 40일째 크롤 안 옴 |
| **네이버** | **최소 10 URL** | 고유 문구 검색 → cue URL 등장 | ✅ **홈·/about·/companies·/jobs·/spike·/prep + 글 2편 + 공고 1건** |
| **빙** | **0개** | 글 고유 문구 `"Kafka를 외우지 말고"` → 결과 없음 | ❌ IndexNow 를 매 크롤마다 쏘는데 안 들어감 |

### 🔴 이 대비가 말해주는 것 — 진단이 바뀐다

**콘텐츠 문제가 아니다.** 네이버는 같은 페이지를 색인했다. 개별 글과 공고 페이지까지 들어갔다.
같은 HTML·같은 스키마·같은 본문인데 **한 엔진은 넣고 한 엔진은 안 넣는다.**

→ 구글 0개의 원인은 **페이지 품질이 아니라 도메인 단위 크롤 수요**다.
→ `SEO_GEO.md` §3~§20(페이지 규격)을 더 손봐도 구글 색인은 안 움직일 가능성이 크다.
→ 움직이는 건 §23(내부 링크)과 **색인 API** 다. H1·H4 의 중요도가 올라간다.

### 빙이 0인 건 별개 문제다

IndexNow 는 매 크롤마다 `pinged 29 urls ok=true` 를 찍고 있는데 색인이 0이다.
**핑이 갔다는 것과 받아들여졌다는 건 다르다.** 빙 웹마스터 계정이 없어서 지금껏 확인할 방법이 없었다.
빙은 **ChatGPT 검색의 백엔드**라 GEO 와 직결된다 — 여기가 0이면 ChatGPT 에 인용될 일도 없다.

| 할 것 | 누가 |
|---|---|
| 빙 웹마스터 계정 개설 + GSC 에서 사이트 가져오기 (5분) | 🙋 사람 — 계정 생성은 내가 못 한다 |
| 네이버 서치어드바이저 상태 확인 | 🙋 사람 — 브라우저 확장 사이트 제한에 막힘 (소유확인 파일 3개가 저장소에 있으니 등록은 돼 있을 것) |

> 📌 **일반화:** 새 사이트를 볼 때 **구글만 보지 마라.** 엔진별 색인을 나란히 재면
> "우리 콘텐츠가 문제인가"와 "이 엔진이 안 오는 건가"를 **한 번에 가를 수 있다.**
> 한 엔진이라도 색인했으면 콘텐츠는 무죄다.

## 다른 사이트에 옮길 때 — 체크리스트

cue 에서 배운 걸 mark·notes·heyreci·apex 에 적용할 때 **이 순서로 확인**한다.

1. **GSC 에서 색인 수를 먼저 본다.** 점검기 FAIL 0 을 믿고 시작하지 마라
2. **고아 페이지를 센다** — `seo_check.py --live --domain <도메인> --orphans`
3. 허브가 목록을 **JS 로만 그리는지** 본다. 그러면 그 허브는 없는 것이다

6. **이 파일에 실험을 먼저 적고** 조치한다. 나중에 적으려면 이미 못 적는다

### 🔎 회사×직군 페이지가 실제로 랭크된다 — H5 의 전제가 증명됐다

```
"카카오페이 백엔드 면접 질문"  → /company/kakao/backend
"면접 잡혔는데 공고 재등록"     → /playbook/final-rejection-risk
"AI 모의면접 소리내어 연습"    → 홈·/about·/companies 등 6건
```

H5 는 "회사×직군 롱테일이 진짜 자산인데 sitemap 비중이 6%뿐이고 15일 살다 죽는 공고가 81%"라는
**가설**이었다. **네이버가 먼저 증명해 줬다** — 우리가 자산이라고 부른 그 페이지가 실제로 잡힌다.
구글에서 안 잡히는 건 페이지 품질이 아니라 **예산 배분**이라는 쪽으로 무게가 더 실린다.

### ⚠️ lastmod 를 채울 때 지킨 선 — 여기서 욕심내면 전부 무효가 된다

`/about`·`/faq`·`/privacy`·`/pricing`·`/prep/*` 는 **일부러 비워 뒀다.**
크롤러는 하루 2회 배포되는데 이 페이지들의 화면은 안 바뀐다. 배포 시각을 lastmod 로 내밀면
매일 "바뀌었다"고 거짓말하는 꼴이고, **반복되면 크롤러가 그 사이트의 lastmod 를 통째로 무시한다.**
→ 규칙: **lastmod 는 "그 페이지를 그리는 데이터가 바뀐 시각"이지 배포 시각이 아니다.**
